# 프로젝트 계획 — myworld (오픈월드, Godot, Web)

목표

- Godot 엔진으로 오픈월드를 제작하고, 웹(WASM) 빌드로 모든 디바이스에서 실행 가능하도록 한다.

우선순위(단계별)

1. 초기설정 및 골격 (오늘 작업)
   - Godot 프로젝트 초기 파일(godot/project.godot), 기본 씬(godot/scenes/Main.tscn), 초기 스크립트 작성
   - 코드 규약, 포맷터, 훅 적용(이미 적용됨)
   - WORKLOG 자동화 스크립트 추가(이미 적용됨)
2. 플레이어 및 카메라 기본 구현
   - 간단한 이동 가능한 플레이어(키보드/터치 지원)
   - 카메라 따라오기
3. 월드 프로토타입
   - 타일/오브젝트 기반의 간단한 월드 생성기
   - 페이징/스트리밍(큰 월드 대비) 아키텍처 설계
4. 상호작용 및 UI
   - 인벤토리, 상호작용(픽업, NPC 대화) 구조 설계
5. 최적화 및 웹 빌드
   - Godot 웹 템플릿 준비(빌드 워크플로 추가)
   - 성능 프로파일링 및 용량 최적화
6. 멀티플랫폼 테스트 및 배포
   - GitHub Pages 혹은 별도 호스팅에 웹 배포

개발 환경 및 규약 (요약)

- 코드 주석: 한국어
- GDScript 스타일: 들여쓰기 2-space (프로젝트 표준)
- 포맷터/훅: prettier, eslint(자바스크립트), husky, lint-staged(이미 설정됨)

초기 작업 제안 (제가 바로 시작할 작업)

- 위에 만든 초기 골격 파일(godot 폴더) 커밋 & 푸시 (지금 완료 예정)
- 플레이어(간단한)와 카메라를 우선 구현할지, 아니면 먼저 월드 생성(간단한 타일)부터 할지 선택 필요
